# geometric_lib

Библиотека на Python для расчёта площади и периметра круга, квадрата, прямоугольника и треугольника.

## Модули

- [`circle.py`](../circle.py)  площадь круга и длина окружности.
- [`square.py`](../square.py)  площадь и периметр квадрата.
- [`rectangle.py`](../rectangle.py)  площадь и периметр прямоугольника.
- [`triangle.py`](../triangle.py)  площадь и периметр треугольника.

## Функции

### `circle.area(r)`

- Принимает радиус `r` типа `int` или `float`.
- Возвращает площадь круга типа `float`.
- Формула: `S = πr²`.


### `circle.perimeter(r)`

- Принимает радиус `r` типа `int` или `float`.
- Возвращает длину окружности типа `float`.
- Формула: `P = 2πr`.


### `square.area(a)`

- Принимает длину стороны `a` типа `int` или `float`.
- Возвращает площадь квадрата; тип результата совпадает с типом аргумента.
- Формула: `S = a²`.


### `square.perimeter(a)`

- Принимает длину стороны `a` типа `int` или `float`.
- Возвращает периметр квадрата; тип результата совпадает с типом аргумента.
- Формула: `P = 4a`.

### Прямоугольник и треугольник

| Функция | Аргументы | Что возвращает |
| --- | --- | --- |
| `rectangle.area(a, b)` | Две стороны | Площадь `a * b` |
| `rectangle.perimeter(a, b)` | Две стороны | Периметр `2 * (a + b)` |
| `triangle.area(a, h)` | Основание и высота к нему | Площадь `a * h / 2` |
| `triangle.perimeter(a, b, c)` | Три стороны | Периметр `a + b + c` |

Размеры задаются в одних единицах. Нулевые размеры допускаются, отрицательные вызывают `ValueError`. При передаче строки или `None` вместо числа возникает `TypeError`.
Для периметра треугольника сумма любых двух сторон должна быть не меньше третьей. При равенстве функция возвращает периметр вырожденного треугольника. Если сумма меньше, возникает `ValueError`.

## Пример использования

```python
import circle
import rectangle
import square
import triangle

print("Площадь круга:", circle.area(3))
print("Длина окружности:", circle.perimeter(3))
print("Площадь квадрата:", square.area(3))
print("Периметр квадрата:", square.perimeter(3))
print(rectangle.area(3, 5))
print(rectangle.perimeter(3, 5))
print(triangle.area(6, 4))
print(triangle.perimeter(3, 4, 5))
```
