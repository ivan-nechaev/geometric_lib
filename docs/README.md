# geometric_lib

Библиотека на Python для расчёта площади круга и квадрата, длины окружности и периметра квадрата.

## Модули

- [`circle.py`](../circle.py)  площадь круга и длина окружности.
- [`square.py`](../square.py)  площадь и периметр квадрата.

## Функции

### `circle.area(r)`

- Принимает радиус `r` типа `int` или `float`.
- Возвращает площадь круга типа `float`.
- Формула: `S = πr²`.


### `circle.perimeter(r)`

- Принимает радиус `r` типа `int` или `float`.
- Возвращает длину окружности типа `float`.
- Формула: `P = 2πr`.


### `square.area(a)`

- Принимает длину стороны `a` типа `int` или `float`.
- Возвращает площадь квадрата; тип результата совпадает с типом аргумента.
- Формула: `S = a²`.


### `square.perimeter(a)`

- Принимает длину стороны `a` типа `int` или `float`.
- Возвращает периметр квадрата; тип результата совпадает с типом аргумента.
- Формула: `P = 4a`.


## Пример использования

```python
import circle
import square

print("Площадь круга:", circle.area(3))
print("Длина окружности:", circle.perimeter(3))
print("Площадь квадрата:", square.area(3))
print("Периметр квадрата:", square.perimeter(3))
```

Результат:
```
Площадь круга: 28.274333882308138
Длина окружности: 18.84955592153876
Площадь квадрата: 9
Периметр квадрата: 12
```
