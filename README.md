## Общее описание

**Geometric Library** — учебная библиотека на Python для вычисления геометрических величин.

Библиотека позволяет находить площадь и периметр круга, квадрата, прямоугольника и треугольника. Для каждой фигуры есть свой модуль с функциями `area` и `perimeter`.

Каждая функция принимает размеры фигуры и возвращает результат, который можно использовать в дальнейших вычислениях или вывести на экран.

### Возможности

- Расчёт площади круга и длины окружности по радиусу.
- Расчёт площади и периметра квадрата по длине стороны.
- Расчёт площади и периметра прямоугольника по двум сторонам.
- Расчёт площади треугольника по основанию и высоте, периметра по трём сторонам.
- Работа с целыми числами и числами с плавающей точкой.
